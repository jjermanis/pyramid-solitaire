# pyramid-solitaire
Playing classic Pyramid solitaire 

## Overview
A classic version of the solitaire game called Pyramid. To win, remove all cards from the starting pyramid.

## Description
This is a standard version of the Pyramid solitaire game. Cards are stack in rows, with the first row having one card. The second row has two cards - it partially covers the first row. This continues, with the seventh row having seven cards on top.

Cards can be removed by clicking two available cards that total 13. An ace is worth 1, a Jack is worth 11, a Queen is worth 12, a King is worth 13. For a King, you can click those alone without another card. You can click the uncovered cards in the pyramid. There is also the deck of cards in the lower-left corner. You can draw through those to get a card to click to a total 13.

The game is won when all of the pyramid has been removed.
